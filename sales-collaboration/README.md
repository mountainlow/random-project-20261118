# 销售流程优化与三端协同管理

本目录保存销售流程、销售／技术支持／商务分工、品牌模板及会议讨论稿。

- `销售流程优化与三端协同管理_会议讨论稿.pptx`：16页可编辑演示文稿。
- `销售流程优化与三端协同管理_会议讨论稿.pdf`：会议阅读版。
- `销售管理体系_品牌模板.potx`：PowerPoint模板。
- `销售管理体系_品牌模板.pptx`：模板的可编辑版本。
- `销售流程图及三端任务分工.xmind`：原流程整理及优化分工。

文件保留原名，`manifest.json`记录字节数和SHA-256，用于下载核对。

内容为会议讨论建议，涉及职责、审批权限及实施计划的规则须结合公司实际确定。
